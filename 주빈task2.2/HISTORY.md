## Step 2 — 문장 단위 분리

### 문제 인식

리뷰 한 건 안에 긍정·부정이 혼재한다.
예: "카메라는 최고인데 배터리가 너무 약하고 발열도 심해요. 전반적으로는 만족합니다."
→ 리뷰 전체 감성: `weak_positive` → 불만 문장이 분석에서 누락됨

### 해결책

리뷰를 **문장 단위로 분리** 후 각 문장에 개별 inference 적용.
`review_id + sentence_idx`로 인덱싱하여 나중에 같은 리뷰 내 불만 공존 패턴 분석 가능.

### v1 (regex) → v2 (kss) 개선

초기 regex 방식은 `\n`과 `.!?` 기준으로 단순 분리 → 8자짜리 감탄사, 이모지 단문 등 쓰레기 문장 대거 포함.
**kss (Korean Sentence Splitter)** 로 교체하고 품질 필터 강화:
- 최소 15자, 최대 300자
- 한글 비율 30% 미만 제외
- 반복 문자(ㅡㅡㅡ, ---) 제외
- 18코어 병렬 처리

| 구분 | regex (v1) | kss (v2) |
|------|-----------|---------|
| 총 문장 | 37,601개 | **28,698개** |
| 10자 이하 문장 | 다수 | **0개** |
| 평균 문장 길이 | 짧음 | **47자** |
| 부정 문장 | 5,586개 (14.9%) | **2,705개 (9.4%)** |
| 부정 포함 리뷰 | 1,504개 | **1,212개** |

→ 쓰레기 문장 8,903개 제거. 부정 비율 감소는 품질 향상의 증거 (감탄사/단문이 부정으로 잡히던 것 제거됨)

### 최종 결과 (`sentence_sentiments.csv`)

| 구분 | 수치 |
|------|------|
| 총 리뷰 | 2,757개 |
| 총 문장 | 28,698개 (리뷰당 평균 10.4문장) |
| 평균 문장 길이 | 47자 (중앙값 42자) |
| 부정 문장 (is_negative=True) | 2,705개 (9.4%) |
| 부정 문장 포함 리뷰 | 1,212개 |

**rating × 부정 문장 분포**

| rating | negative | weak_negative | 부정 비율 |
|--------|----------|---------------|---------|
| 1 | 340 | 148 | **84%** |
| 2 | 33 | 26 | 75% |
| 3 | 53 | 71 | 52% |
| 4 | 68 | 174 | 20% |
| 5 | 411 | 1,381 | **6.7%** |

→ rating 5 리뷰에서 **1,792개의 부정 문장** — 5점을 주면서도 특정 불만을 토로한 혼재형 리뷰의 숨겨진 불만
→ 리뷰 수준 부정 314개 → 문장 수준 부정 포함 리뷰 1,212개 (**3.9배** 확장)

브랜드 불만이 독립 클러스터를 형성하지 못함 — **데이터가 3분류 가설을 지지하지 않음**

## Step 4 — 클러스터링 v1 (k=6, regex 기준)

### 파이프라인

```
부정 문장 5,436개 (쓰레기 문장 150개 제거 후)
  → jhgan/ko-sroberta-multitask 임베딩 (768d)
  → UMAP 차원 축소 (768d → 30d, n_neighbors=30)
  → KMeans (k=6, n_init=20, silhouette=0.4447)
```

### 최종 클러스터 결과

| 클러스터 | 문장 수 | 평균 별점 | 주제 |
|---------|--------|---------|------|
| **C1** | 1,086 | **3.16** | **쿠팡 배송/포장/CS** — 택배 분실, 180만원 포장 불량 |
| **C2** | 900 | 4.50 | **쿠팡 교환 절차** — 개인정보, 핸드폰 없이 8일, 유심 오류 |
| **C3** | 857 | 4.77 | **제품 성능 불량** — 버벅거림, 렉, 터치 오작동 |
| **C5** | 444 | 4.88 | **제품 발열/마이그레이션** — 안드오토 과열, 데이터 이전 실패 |
| **C4** | 348 | 4.72 | **가격 불만** — "줄 만한가", "살 이유가" |
| **C0** | 1,801 | 4.62 | **혼재** — 감정 표현 위주, 다수 주제 혼합 |

### 핵심 발견

**① 브랜드 불만은 독립 클러스터를 형성하지 않음**
- 브랜드 언급("갤럭시 발열", "아이폰 비싸")이 제품/쿠팡 불만 문장과 의미적으로 분리되지 않음
- 가격 불만(C4) 안에 일부 섞여 있음

**② 쿠팡 불만이 두 갈래로 분리됨**
- C1: 물리적 문제 (배송, 포장) → 평균 별점 3.16으로 가장 낮음. 분노 강도 최고
- C2: 절차적 문제 (교환, 개인정보, 응대) → 별점은 높지만 불만 내용은 구조적

**③ 제품 불만도 두 갈래로 분리됨**
- C3: 즉각적 성능 불량 (렉, 터치)
- C5: 사용 중 발생하는 문제 (발열, 데이터 이전) → 별점이 가장 높음(4.88) = 전반적 만족이지만 특정 불만

**④ C0(1,801개) 혼재 클러스터가 여전히 큼**
- "말이 됩니까", "사람 차별" 등 감정 표현 위주의 단문 불만
- 특정 주제에 귀속되지 않는 일반적 분노 표현이 하나의 공간으로 뭉쳐있음

### 옵션 E — Business Value 도출
